About Benjamin Cook & SWEEPR Cleaner

SWEEPR Cleaner is designed, built, and maintained by Benjamin Cook—an independent software developer operating as a UK sole trader—for people who want a fast native Rust disk cleaner without bundled bloatware, scareware popups, or hidden background telemetry.

1. Why I Built a Lean Native Rust PC Cleaner

Too many legacy PC utilities grew into what they claimed to fix: multi-hundred-megabyte installers that bundle unrelated browser toolbars, nag users with fabricated “critical registry error” alerts, and keep background updaters running all day.

I built SWEEPR Cleaner around a simpler engineering goal: compile a compact, verifiable native Rust & Tauri v2 desktop binary (SWEEPRCleaner.exe is 7,085,912 bytes / 6.76 MiB) that treats disk cleanup as deterministic filesystem engineering:

  • Hard-coded safety boundaries: SWEEPR’s Rust safety module refuses to target personal user libraries (Documents, Desktop, Pictures, Videos, Audio), system roots, symlinks, NTFS junctions, and OneDrive cloud placeholders (FILE_ATTRIBUTE_REPARSE_POINT). You can inspect any path rule in our Safe-to-Delete Path Checker.
  • Honest Free Tier & 7-Day Undo Quarantine: SWEEPR Free provides unlimited Temp & Browser Cache Clean (temp, chrome, edge, brave, firefox) routed directly to your OS Recycle Bin or Trash with zero byte cap. SWEEPR Pro unlocks Deep GPU/AI/Dev caches, exact 2-stage SHA-256 duplicate detection, App Uninstaller, Scheduler, and a local 7-Day Undo Quarantine (configurable 2–10 GB disk budget, 5 GB default, same-volume O(1) move, FIFO eviction; OS Recycle Bin fallback if file exceeds budget; excludes shredded files, browser DBs, and registry edits).
  • Zero-Telemetry / Offline Mode by default: Out of the box, telemetry_enabled defaults to false. Unless you explicitly opt in under Settings, the desktop app sends zero background analytics or crash reports. All 71 cross-OS cleanup rules (455 path patterns: 27 Windows / 24 macOS / 20 Linux) are published in docs/public-rules-catalog.json.
