What SWEEPR Never Touches

Before any scan or deletion runs, safety::is_safe_root, is_safe_scan_root, and is_link_like enforce five compile-time boundary guards:

Safety Guard (safety.rs) Protected Paths & Conditions
1. Shallow & Relative Path Guard
is_safe_root (8–19)		 Rejects relative paths and paths with < 2 normal segments (except std::env::temp_dir()).
2. Personal User Libraries
is_safe_root (21–40)		 Hard-denies home_dir, Documents, Desktop, Pictures, Videos, Audio / Music, and AppData (data_dir / data_local_dir / config_dir) roots.
3. Downloads 30-Day + 5-Signal Guard
is_safe_scan_root (60–74)		 Downloads refused unless min_age_hours >= 720 (30 days) AND file passes mtime, ctime, atime, Recent\*.lnk, and access_mode(0).share_mode(0) checks (scanner.rs:129–168).
4. OS & Program Roots
is_safe_root (41–55)		 Denies Windows SystemRoot, ProgramFiles, ProgramFiles(x86), ProgramData; Unix /, /usr, /bin, /etc, /var, /System, /Library, /Applications.
5. Symlinks, Junctions & OneDrive
is_link_like / has_symlink_component (80–134)		 Rejects .. parent traversal, symlinks, NTFS junctions, and Windows FILE_ATTRIBUTE_REPARSE_POINT (0x400) OneDrive cloud placeholders across every ancestor.
