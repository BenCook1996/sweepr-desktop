What Happened to CleanMyPC After April 2025

Unlike CleanMyMac—which MacPaw continues to develop actively for macOS—CleanMyPC paused active feature work in late 2021 and was officially sunsetted on April 22, 2025. Existing subscribers received legacy lifetime builds, while new sales ended. That leaves older CleanMyPC rule sets blind to where modern Windows 11 builds actually accumulate 10–50 GB of clutter: Windows 11 feature-update staging, Edge WebView2 runtimes, DirectX shader caches, and local AI/game depots.

SWEEPR Cleaner keeps CleanMyPC’s clean editorial clarity while adding actively audited paths—including a 1-click Windows Hibernation toggle showing hiberfil.sys size via powercfg /hibernate on|off with an explicit Fast Startup caveat so you reclaim disk space without breaking Fast Startup unexpectedly—plus 7-Day Undo Quarantine (configurable 2–10 GB disk budget, 5 GB default, same-volume O(1) move; OS Recycle Bin fallback if file exceeds budget; excludes shredded files, browser DBs, and registry edits).
