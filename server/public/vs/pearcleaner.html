Why Uninstalling Apps Only Solves Part of SSD Bloat

Developer toolchains (ComfyUI temp outputs, Xcode DerivedData, Docker images) and everyday apps (Discord, Spotify) silently accumulate 30–80 GB while remaining installed. SWEEPR targets those safe caches without requiring you to uninstall anything, includes local macOS maintenance helpers—Spotlight reindex (mdutil), LaunchServices refresh (lsregister), and DNS cache flush (dscacheutil/mDNSResponder)—while publishing its full rule catalog in docs/public-rules-catalog.json, enforcing Zero-Telemetry / Offline Mode by default, and verifying every build via /release-manifest.json (Windows SSL.com Authenticode Individual Validation (IV) (CN=Benjamin Cook, thumbprint 1800DBEA6FE847D384E549D02CA372C3D45D8B81) via Get-AuthenticodeSignature/certutil -hashfile, and macOS shasum/codesign/spctl).
