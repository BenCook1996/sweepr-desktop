2. AppCleaner by Freemacsoft

Free Mac Uninstaller · Classic Drag-and-Drop

The classic free macOS drag-and-drop uninstaller that inspired Pearcleaner. Simple and reliable for removing standalone apps to Trash, though it lacks active app cache rules, SHA-256 duplicate scanning, and cross-platform Windows coverage.

3. CleanMyMac

macOS Visual Suite · ~150+ MB

Includes an Uninstaller module alongside Smart Care and Moonlock malware protection, though it installs a ~150+ MB macOS suite with a Menu monitor daemon and lacks Windows support or a 7-day rollback vault. Compare SWEEPR vs CleanMyMac.

4. OnyX

Freeware macOS Maintenance Scripts

Titanium Software’s free macOS maintenance utility for running low-level system scripts, rebuilding Spotlight/LaunchServices indexes, and toggling hidden defaults, without pre-scan GB previews or rollback. Compare SWEEPR vs OnyX.

5. DaisyDisk

~$9.99 One-Time · Sunburst Disk Map

Fast macOS sunburst visualizer for spotting massive folders in ~/Library so you can drag them manually to the permanent Collector. Does not auto-classify caches or find duplicates; compare SWEEPR vs DaisyDisk.
