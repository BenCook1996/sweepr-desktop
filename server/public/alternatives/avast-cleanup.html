2. Microsoft PC Manager + Windows Storage Sense

Official Windows 11 · Free

Microsoft’s own Windows 11 Store utility pairs with Storage Sense to handle RAM boost, startup app toggles, Defender checks, and scheduled temp sweeps with zero third-party renewal traps. Its limitation is blind spots: it leaves Steam depots, NVIDIA shader leftovers, and AI/dev caches untouched.

3. BleachBit

Open Source GPLv3 · Zero Telemetry

100% free and open source by Andrew Ziem with zero background services, zero ads, and built-in file/free-space shredding. Its GTK3 UI feels dated and offers no Undo Quarantine, so check boxes carefully—see our SWEEPR vs BleachBit breakdown.

4. Wise Disk Cleaner

Lightweight Freeware · ~8.5 MB

An ~8.5–8.6 MB Windows freeware cleaner (also available as a portable ZIP) offering fast temp/browser cleanup, System Slimmer, and HDD defrag/SSD TRIM without bundling a registry cleaner. It lacks duplicate detection, file shredding, and 7-day quarantine; compare details in SWEEPR vs Wise Disk Cleaner.

5. Bulk Crap Uninstaller (BCUninstaller)

Open Source Apache 2.0 · Uninstaller

A free open-source Windows uninstaller built to strip OEM bloatware, Store/UWP apps, and leftover directories in batches. Excellent when replacing Avast’s bloatware removal role, though it is an uninstaller rather than an everyday shader or update cache cleaner.
