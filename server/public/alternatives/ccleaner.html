2. Windows Storage Sense + Microsoft PC Manager

Built Into Windows 11 · Free

Microsoft’s native Storage Sense automatically empties Recycle Bin and basic temporary files on a schedule with zero security risk. Its limitation is blind spots: it leaves Steam depots, NVIDIA shader leftovers, JetBrains versions, and Discord Media Blob caches untouched.

3. BleachBit

Open Source GPLv3 · Power Users

Free, open-source Python/GTK cleaner popular for privacy shredding and custom winapp2.ini rules. See our full SWEEPR vs BleachBit comparison—BleachBit has no undo quarantine and can erase active session files if checkboxes are picked hastily.

4. WizTree

MFT Disk Visualizer · Free Personal Use

Reads the NTFS Master File Table in seconds to show a treemap of your biggest folders. Essential for diagnosis, though it gives no safety verdicts—you can validate paths WizTree finds using SWEEPR’s free Safe-to-Delete Path Checker.

5. Geek Uninstaller

Portable Uninstaller · Free Single EXE

A tiny single-executable Windows app uninstaller that scans leftovers right after removing an application. Great specifically for uninstalling programs, though it does not clean ongoing app caches, GPU shaders, or duplicate files.

Skip Aggressive Registry Cleaners on Windows 11

Many legacy tune-up suites (such as CCleaner, Glary Utilities, IObit Advanced SystemCare, and standalone tools like Wise Registry Cleaner—distinct from Wise Disk Cleaner, which focuses only on disk files—along with discontinued apps like CleanMyPC) have historically advertised “fix 1,000 registry errors” to justify a paid upgrade. On Windows 10 and 11, cleaning harmless registry keys saves virtually zero storage while risking broken COM/MSI associations (especially in Package Cache). SWEEPR applies a clear policy: no aggressive registry wiping — Microsoft advises against Win11 registry cleaners; optional safe backed-up HKCU broken App Paths/Run repair in Pro, focusing instead on verifiable multi-GB cache and orphaned build cleanup.
