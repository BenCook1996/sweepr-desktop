```markdown
Sweepr Cleaner is a modern, ultra-lightweight PC cleaner and storage optimizer engineered in native Rust for Windows 10, Windows 11, and macOS.

Designed specifically as an antidote to legacy desktop cleaners that have grown bloated with background telemetry daemons, adware bundles, and aggressive upsell popups, Sweepr Cleaner delivers rapid disk reclamation with zero resident memory footprint.

### Key Highlights
- **⚡ Native Rust Engine (<7 MB):** Launches instantly, consumes under 40 MB of RAM during active execution, and scans nested system directories in under 60 seconds.
- **🛑 Zero Background Processes:** Runs strictly on demand. No resident background services, no startup tray daemons, and zero CPU/RAM impact when closed.
- **🛡️ 7-Day Quarantine & 1-Click Rollback:** Eliminates the risk of broken apps. Cleaned caches and temporary files are isolated in a local 7-day quarantine vault so you can restore anything with a single click.
- **🔍 Modern Storage Sinks:** Targets gigabytes of hidden bloat ignored by traditional cleaners: DirectX 11/12 and Vulkan shader caches, NVIDIA DXCache, AMD DxCache, Steam depotcache chunks, Discord/Spotify Electron bloat, and WSL2/Docker virtual disks.
- **🧹 Smart App Uninstaller:** Drag-and-drop uninstallation that purges orphaned leftovers and stale AppData folders left behind by standard Windows uninstalls.
- **📑 Cryptographic Duplicate Finder:** Uses cryptographic SHA-256 byte comparisons to find true duplicate files without false positives.
- **🔒 Secure File Shredder:** Meets DoD 5220.22-M sanitization standards for permanent, unrecoverable deletion of sensitive personal files.
```
