### Full Description (Markdown Format)

```markdown
Sweepr Cleaner is a modern, ultra-lightweight PC cleaner and privacy optimization utility built in native Rust. 

Designed specifically as an alternative to legacy PC cleaners that have become bloated with background daemons, telemetry, and aggressive upsell popups, Sweepr Cleaner delivers maximum disk recovery with zero system overhead.

### Why Sweepr Cleaner?
- **⚡ Native Rust Engine (<15 MB):** Starts instantly, consumes under 40 MB of RAM during execution, and finishes deep system scans in under 60 seconds.
- **🛑 Zero Background Processes:** Sweepr runs strictly on-demand. No startup daemons, no background services, and no background memory bloat.
- **🛡️ 7-Day Quarantine & 1-Click Rollback:** Unlike aggressive registry or disk wipers, Sweepr isolates removed caches into a secure quarantine. If an app ever needs a file back, restore it instantly with one click.
- **🔍 DeepClean Cache Engine:** Targets GBs of hidden bloat across Windows Temp, AppData, browser caches (Chrome, Edge, Firefox, Brave), GPU shader caches, and diagnostic crash dumps.
- **🧹 Smart App Uninstaller:** Discovers and erases stubborn leftovers, orphaned folders, and stale registry keys left behind by standard Windows uninstalls.
- **📑 Duplicate File Finder:** Uses cryptographic SHA-256 byte verification to safely detect and remove identical duplicate files and videos without false positives.
- **🔒 Secure File Shredder:** Meets DoD 5220.22-M sanitization standards for permanent, unrecoverable deletion of sensitive personal files.
- **💻 Cross-Platform Coverage:** A single license covers up to 3 PCs (Windows, Mac, Linux) and 2 mobile devices (Android, iOS).
```
